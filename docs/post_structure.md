# Структура [`Post`](../../backend/parser-service/src/parser/data_structures.py)

Структура представляет собой описание поста из Вконтакте для удобного взаимодействия с ними

## Поля структуры

Структура [`Post`](../../backend/parser-service/src/parser/data_structures.py) содержит такие поля как:
- `post_text:str`: Текст поста
- `first_image_url:str`: Ссылка на первое изображение из поста
- `post_link:str`: Ссылка на пост
- `title:str`: Заголовок поста (Пока не используется)
